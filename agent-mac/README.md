# 美国加州 M6 Mac mini 租赁页面

CalDock 前端预览。按用户选中的第 2 套「加州暮色」设计，使用深棕黑背景、暖琥珀色按钮及日落硬件摄影；保留介绍结构，下方价格区使用用户提供的三档深色方案卡。通过 GitHub Pages 发布页面和付款流程预览。

共同开发入口：[开发指南](../docs/DEVELOPMENT.md) · [Claude 使用说明](../docs/CLAUDE_WORKFLOW.md)。品牌改名已暂停，当前仍用 CalDock。

设计与生成素材记录：[California Afterglow](docs/design/california-afterglow.md)。

- 月付：$199，每月支付。
- 季付：折合 $169/月，一次支付 $507，服务 3 个月。
- 年付：折合 $129/月，一次支付 $1,548，服务 12 个月，标记「主推」。
- 下方三档方案同步金额、付款周期和条款；点击继续付款进入所选 `interval=month|quarter|year` 的付款预览。已有订单保留其历史金额，新的定价只应用于新订单。
- 登录、客户中心及订单流程使用 `https://craftos.app/caldock/`，与 `/api/caldock` 保持同源。下单金额由后端确定，待付款订单不会被前端标记为已付款。
- 付款尚未接通；本地付款页不会发起扣款或显示虚假的成功状态。
- 顶部只保留 CalDock、页内定位和中英切换；原站下载栏、目录页脚及合规徽章已删除。“写给老板的演示”推广区及其链接也已删除。价格由用户确认；库存、交付及服务条款仍是页面预览内容。
- 全部资源与字体位于 `public/assets`；未引入原站统计、第三方桥接脚本或账号系统。

## 当前页面的硬件文案

当前页面使用 M6、12 核 CPU、12 核 GPU、16GB 统一内存、256GB SSD 的产品文案。若要调整硬件或正式对外确认可售配置，按用户确认和官方来源核实，不把旧记录当作重新验证。

## 本地运行

推荐 Node.js 22；在本目录运行 `npm ci`，然后 `npm run dev -- --port 4173`。

`npm run build` 输出 `dist/client` 静态文件与保留的 Sites Worker。`npm run test:sites` 检查部署运行时契约。

## GitHub Pages

资源使用相对路径，付款页面使用查询参数路由，支持 GitHub Pages 的仓库子目录和直接刷新。根目录的 `.github/workflows/pages.yml` 在 main 更新时自动构建并发布 `agent-mac/dist/client`。

页面使用直接付款与退款表述，不提供积分、充值或余额机制。页面、导航及付款页统一使用深色背景，所有标题与首屏余量数字加粗。

## 账号、订单与分销

- Google / Apple 登录页面；真实供应商应用尚待配置，按钮不会模拟登录成功。
- 客户中心：自己的订单、订单详情、待付款取消、续订设置、显示名称修改及退出。
- 分销中心：专属链接、复制链接、邀请注册与订单归因、佣金明细。
- 管理后台：订单搜索/筛选、已付款订单的配置与交付、客户/分销伙伴、佣金审核与线下结算记录、佣金规则及版本冲突保护。
- `?view=account&demo=1&role=customer` 和 `?view=admin&demo=1&role=admin` 是明确标识的交互演示，仅使用浏览器中的虚构数据；不调用真实业务 API、不创建真实账号或扣款。
- 后端复用用户指定的 `Yonge6/onelaser-workos-api`；CalDock 与 Work OS 的数据库表、身份、Cookie、管理员与审计记录独立。
- 实际付款平台尚未接通。佣金默认比例为 0，仅可信支付适配器确认付款后产生；不会自动打款。演示数据中的比例/金额是示例。
- `npm run test:commerce` 验证账号路由、演示隔离、归因来源与价格格式。后端权限与订单测试在后端仓库运行。
