# Agent Mac 页面 Implementation Plan

**Goal:** 复刻 Agent.Space Mac 页面，并改为美国加州 M6 Mac mini，本页完成月付/年付选择后直接进入付款页。

**Architecture:** 复用用户提供的 HTML、CSS、SVG，删除第三方脚本与统计；React 仅负责套餐状态、导航与付款页。页面所有图形和字体存本地。选项同步到页面各价格入口，并通过 URL 传入付款页。

**Tech Stack:** React 19, Vite 6, local HTML/CSS/SVG.

1. 从保存的页面提取正文、样式和原始矢量图，下载缺失字体与品牌图。
2. 全站地区统一美国加州，芯片 M6，配置表更新为 Apple 官方规格的 12 核 CPU / 12 核 GPU，保留 16GB / 256GB。
3. 参考用户截图，在首屏展示月付 $160、年付 $1,440（$120/月）两项，同页选择，按钮和周期条款同步更新。
4. 恢复 FAQ、导航、语言选择、Cookie 设置和滚动动画。预订入口不跳原站账单，直接进入本地 /checkout。
5. 付款页保留所选周期、总额、产品和条款。正式支付链接由 VITE_CHECKOUT_MONTH_URL / VITE_CHECKOUT_YEAR_URL 提供；缺失时明确显示付款未开放，不模拟成功。
6. 浏览器检查桌面、390px 手机端、套餐切换、FAQ 和付款来回跳转，构建并保存 design-qa.md。
