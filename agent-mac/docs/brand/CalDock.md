# CalDock

Cal + Dock: California hosting, a persistent dock for always-on Mac workstations.

Final symbol: `public/assets/caldock-logo.png`. Generated with the built-in image generation tool, transparent PNG, 1254 × 1254 pixels. The original generated artifact is preserved; the project copy is on DevSSD.

Prompt:

> Use case: logo-brand. Create ONE finished standalone symbol for a new premium cloud Mac mini rental service named CalDock, located in California and offering always-on computers for AI coding agents. Asset is a compact website header icon and favicon, not a mockup or a sheet. Design an original, memorable abstract dock / open C symbol with precise broad geometry and a small sun-like signal accent, using saturated cornflower blue (#83A9FF) with a restrained warm pale orange accent. Calm, confident and extremely legible at 24 pixels. Flat vector-like appearance with sharp clean contours; balanced centered composition; large symbol occupying 80 percent of square canvas. Background must be truly transparent; open negative spaces also transparent. No letters, no words, no typography, no device pictures, no cloud clipart, no presentation board, no shadows, no gradients, no existing company marks. This is the definitive single logo mark to replace all of the old site's brand icons.

Placement: page header, hero badge, software row, checkout brand, favicon. Third-party agent marks (Claude, Codex, OpenCode) remain their own product marks.
